Documentation

HYNA-Stage allows you to instantly spin up ephemeral cloud sandboxes for testing and deployment. No Docker, no YAML, no waiting.

1. Installation

Install the CLI globally via npm to access it anywhere in your terminal.

# Install globally
$ npm i -g @hynaweb/stage

2. Authentication

Link your CLI to your HYNA-Stage account to deploy to your dashboard.

# Authenticate (one-time)
$ hyna-stage login

3. Forge an Environment

Spin up a new sandbox using a pre-configured template. You can specify a Time-To-Live (TTL) in seconds.

# Forge a node environment for 1 hour
$ hyna-stage init node --ttl 3600

4. Marketplace Templates

Browse community templates from the web UI, or list them via the CLI.

# List all available templates
$ hyna-stage templates
